## 退款门槛

订单实收先在真实订单粒度去重。退款事件可靠映射回支付订单后，在学员粒度按统计窗口累计。累计退款 `>=500元` 才进入退费人数和退款金额分子；小额退款学员仍保留在购买人数和实收GMV分母。不得按单笔退款先过滤。

D30口径为在每名学员首笔范围内支付后的30日窗口独立累计退款并应用500元门槛，只纳入观察日时已成熟30日的学员。

## 核心指标

| 指标 | 定义 |
|---|---|
| 实收GMV | 范围内订单层去重后的实收金额 |
| 退款金额 | 满足窗口内学员累计门槛的退款金额 |
| 退费金额占比 | 本组退款金额/同一切面的全部退款金额 |
| GMV退费率 | 退款金额/实收GMV |
| 购买人数 | 组内去重购买学员 |
| 退费人数 | 组内满足门槛的去重学员 |
| 人头退费率 | 退费人数/购买人数 |
| 人均退费金额 | 退款金额/退费人数 |

按产品、渠道、年级、科目拆分时，金额分配到相应订单/退款事件，人数在组内去重。总体人数必须在总体粒度重算。退款时长人数分布用首笔支付到首次合格退款，金额分布用各退款事件与其支付锚点；标准与D30分别计算并标明口径。
