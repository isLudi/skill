# one_dw.dwd_mkt_ai_assistant_asr_record_df

## 1. 中文名称

语音通话 ASR 记录（天工数据地图表 ID `29197`）。

## 2. 表用途

保存录音解析任务及解析文本。数据地图将其标为 Hive 增量表，保留期 30 天。该表本身没有市场顾问部门字段；市场顾问范围需经已限定的人群和通话记录传递。

## 3. 数据粒度

待实测确认。数据地图描述 `id` 为主键、`biz_id` 为业务唯一标识；分区内唯一性以及同一录音 URL 是否多任务尚不能据此认定。

## 4. 查询引擎

Presto。

## 5. 分区字段

`dt` 为天级分区。探查及关联须限定具体分区；增量表与下游全量快照使用同一个 `dt` 时，仍需验证录音覆盖。

## 6. 强制范围限定字段

数据地图未列出部门字段。市场顾问分析应先限定业务人群，再经通话记录的 `call_url` 关联；不可把此表全部记录视为市场顾问数据。

## 7. 字段清单

字段、类型与描述由天工数据地图同步命令维护。

## 8. 常用过滤条件

用户提供的预期 SQL 使用 `dt`、`state = 2` 和非空 `parsed_content` 提取解析完成文本；这些是候选使用条件，覆盖率见后续分区探查。

## 9. 常用 join key

候选：`origin_file_url = service_dw.ods_service_ai_ones_business_copilot__call_record_df.call_url`。需先检查同一分区 URL 的重复任务与跨分区覆盖；未验证前不得按一对一关联聚合电话量。

## 10. 常用 SQL 片段

暂无经过市场顾问范围与去重验证的可复用生产 SQL；候选关联和探查结果见 `knowledge/joins/ai_call_asr_relationship.md`。

## 11. 注意事项

- `parsed_content` 是原文，查询与知识库仅保存长度、空值及聚合统计，不保存原文。
- 数据地图字段信息不证明业务关联或唯一性。

## 12. 分区探查（2026-09-17）

- `dt='20260915'` 共 159,507,223 行（Query `1591080868`）。按 `state` 聚合（Query `1591084542`）：`0/1/2/3/4` 分别为 `116/1,663,699/157,748,922/8,651/83,768` 行。
- `state=2` 中，`parsed_content` 非空且非空串 157,174,987 行；`origin_file_url` 空值或空串 8,507 行。附件 SQL 仅排除 `parsed_content IS NULL`，没有排除空串和空 URL。
- 按附件关联条件做的受限探针（Query `1591086950`）在 88 条通话中发现 3 条通话的 URL 匹配多条 ASR，单条最多匹配 3 条。该探针并未证明 `origin_file_url` 唯一；原 SQL 直接关联会放大这些通话的聚合值。
