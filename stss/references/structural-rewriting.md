# 文章与长文结构改写

用于段落重组、全文重写和跨章关系调整。编辑深度由当前请求确定。围绕同一核心问题重新组织信息，形成完整、连贯的新稿。

## 选择编辑层次

- 句子层：理清搭配、指代、修饰与逻辑。
- 段落层：调整句序，拆合段落，安排主题、证据与解释。
- 篇章层：重排章节和段落，连通标题、引言、正文与结论。

全文改写交付完整重写稿；结构评阅交付具体问题和可执行建议。局部润色保持与任务相称的调整力度。

## 为信息安排去向

长文可在内部记录段落位置、功能、命题、支撑材料、必要条件与保留位置。合并等价复述，把不同证据、条件和分析对象安排在清楚的层次中。

移动主张时一起调整引文、表图指向和前后指代。压缩优先处理无信息的铺垫与复述；扩展则展开材料已有的定义、推理和比较。

## 让段落沿真实关系推进

| 段落关系 | 改写方法 |
| --- | --- |
| 背景到问题 | 选择与问题相关的背景，明确尚待回答的关系 |
| 综述到贡献 | 归纳文献分支，比较已有解释，说明本研究回应的部分 |
| 概念到测量 | 将抽象概念连接到实际观察、题项或指标 |
| 理论到检验 | 说明命题预期、所用证据与支持范围 |
| 总体到局部 | 交代层级、分类标准和比较基准 |
| 结果到解释 | 先呈现发现，再说明相应解释和条件 |
| 发现到建议 | 将发现指向的问题连接到行动对象与适用条件 |

衔接词依照关系选择。通过问题的收束、观察角度的转换、解释层次的推进形成自然过渡。

## 学术长文建立对应关系

引言提出的问题在正文中得到分析，贡献回到具体工作，结论归纳已经展开的发现。

理论假设、变量说明、模型设定、图表与结果叙述保持概念对应。机制、异质性、调节、空间关联与外延讨论各有明确任务。

摘要概括核心内容，引言定位问题，结果呈现证据，讨论阐明意义，结论给出回答。同一发现通过不同层次的表达相互呼应。

学位论文可在章首说明承接的子问题，在章末概括本章发现和下一章的任务。概念、理论、政策演进、案例与实证共同围绕总问题展开。

## 报告连通发现与行动

统计口径提供理解基础，事实发现展示表现，问题解释说明意义，行动建议回应具体需要。总览选择关键发现，分节展开证据与条件。

按读者需要选择标题重心：指标章节说明所测对象，分析小节概括发现，案例突出对象与差异。同级小节采用一致的分类依据。

## 回读整篇文章

检查文章是否仍回答同一问题，标题是否对应内容，关键命题是否与其证据、条件和归属一起保留，重排后的指代和衔接是否连贯。完成可直接阅读的新稿。

## 新编示例

以下情境均为新编。

**衔接措施与观察。** 一篇材料介绍线上预约改革、观察窗口和等待时间变化。可以依次组织措施、观察范围与实际变化，形成清楚的叙述链条。

**衔接总体与条件。** 一节呈现平台使用与项目完成率的关系，下一节讨论不同组织规模的结果。后一节可以承接前一节的适用条件。

**同时呈现总体和例外。** 总体增长与某个子市场缩小各承担不同信息作用，可通过分层叙述形成完整判断。
