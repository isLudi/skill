# 数据、管理与工作报告写作

用于报告语言、管理摘要、线上教育分析、述职、工作总结与日报。完整报告生成见 [报告生成](report-generation.md)，文体选择见 [文体与表达选择](corpus-style-profiles.md)，已有报告重组见 [结构改写](structural-rewriting.md)。

## 依据读者安排信息

业务负责人需要尽早了解发现、影响范围和需要决定的事项；专业分析人员还需要口径、比较设计与证据细节。以本次目录和重点为准，围绕核心问题安排内容。

述职面向管理者时，先回应已经明确的目标，用真实工作和证据解释贡献，再交代影响推进的问题、资源诉求与后续规划。将工作产出与部门目标建立具体联系。

## 分析段落连接判断、证据与行动

段首提出受材料支持的判断，随后给关键数据与基准，解释它对当前问题的含义。将重要变化、结构差异和例外写清，让建议接回相应发现。

标题可概括发现，正文展开依据。图表承载细节，文字选择对读者理解有帮助的信息。行动建议按需要写明对象、动作、依据、条件与验证方式。

管理摘要可按本次要求组织为当前规模、关键发现与管理重点。用户指定触达主题时，围绕触达发现展开对应模块。

## 指标名称对应具体含义

保留当前部门、产品、课程、时间、渠道、年级、样本、去重单位与归因口径。围绕同一对象和比较基准叙述变化。

| 表达对象 | 写清的信息 |
| --- | --- |
| 线索、用户、人头、订单、报科 | 计数单位与去重层级 |
| 退前、退后、留存、转化 | 分子分母、状态截点与期间 |
| 收款、退款、净收、收入、GMV、利润、ROI | 该指标的金额或效率含义 |
| 沟通、好友、外呼、出勤、听课 | 事件、阈值与观察窗口 |
| 顾问、班级、渠道、学生、家长 | 分析层级、付费决策者与学习者的角色 |
| 经营表现、学习过程、学习效果 | 各自对应的观察与评价证据 |

用分组结果呈现差异，以相应设计说明效果。管理目标联系实际基础与验证过程。范围、群体组成和观察完整性在影响比较时与对应发现一起交代。

## 述职与总结写清产出和归属

说明解决的问题、本人职责、交付成果及已观察的结果。将方案设计、测试、提交、上线、反馈和业务效果按实际进展表述。

团队成果与个人贡献各有清楚归属。后续规划使用与当前承诺和安排相符的语气。

## 日报采用三字段自然段

按简短材料整理日报且未指定其他样式时，使用工作内容、完成情况、明日工作计划三个字段，各字段以完整自然语言表达：

```text
工作内容：具体推进了什么事项。
完成情况：已有交付、进度、结果及影响推进的问题。
明日工作计划：已经安排的下一步工作。
```

根据实际描述填入内容；材料未提供明日安排时写“暂未提供”。周报、表格或其他字段依本次要求组织。

## 新编示例

以下示例均为新编。

**写清进展。** 材料记录本地校验完成、正在等待业务确认，完成情况就呈现这两个阶段。

**写清比较。** 两个沟通分组表现不同，报告先交代分组条件和差异，再按已有设计说明如何理解。

**写清指标。** 财务材料给出净收变化时，以净收描述表现；利润与 ROI 使用它们对应的依据。
