# 数据分析、管理与线上教育报告

用于报告语言、管理摘要、述职、工作总结与日报。根据真实材料改善读者理解和决策，不把表达润色扩展为获取新数据、修改指标或执行业务动作。

## 按读者决定信息顺序

业务负责人通常需要尽早了解发现、影响范围和需要作出的决定。专业分析人员还需要口径、比较设计和证据细节。沿用本次指定目录与重点；没有指定时，用问题和证据组织，不强凑固定章节。

面向 +1、+2 等管理者的述职，可将模板中的沟通顺序落实为：先回应已经明确的管理目标与读者关心的问题，再用真实工作与证据解释贡献，随后交代必要问题、约束和支持诉求，最后连接个人规划。不能为迎合领导隐瞒重要不利事实。

盈利性增长、净利润、ROI、部门公共能力等只有在本次背景明确时才成为主线。不把过去某个部门、财年的目标固化为所有报告前提，不将收款、净收或节省工时直接改称利润或 ROI。

## 分析段落要形成可核对的关系

通常先提出一个有依据的判断，再给关键数据与比较基准，说明它对问题意味着什么。已经提供业务建议时，把建议接回对应证据；只有观察性差异时，以待验证的建议或试点表述，不能写成已经确定的最优做法。

- 标题和段首句可以概括实际判断，不能为了吸引注意夸大结论。用户要求陈述句小节标题时，用有证据的完整判断。
- 优先解释关键变化、结构差异、影响范围和例外，不逐个复述表格，也不为减少数字删掉分母或比较条件。
- 已提供图表时，核对正文与图例、单位、时间、样本、分组及注释。模糊截图不猜精确值；读不到的数据单独标记。
- 文图冲突时定位差异并标 `AUTHOR_CHECK`，不能任意挑一个值或静默修表。仅在任务确需且输入足够时进行可复核的派生计算，说明口径。
- 行动建议可写清对象、动作、依据、适用条件和验证方式。负责人、时限、资源、目标值或收益缺失时，不编造成既定安排；新增方案保持“建议/拟/待确认”的阶段属性。

需要管理摘要时，可按“当前规模、关键发现、管理重点”选择组织。用户指定“当前规模、触达发现、管理重点”时沿用该结构，每个要点第一句给出受证据支持的判断。不是触达分析时不强加触达模块。

## 数据与线上教育的语言边界

保留本次已确认的部门、产品、课程范围、期次或自然月、渠道、年级、样本群体、观察窗口、去重单位和归因规则。没有口径材料时沿用原名并提示必要歧义，不调用其他部门的定义填补。

| 容易混淆的表述 | 编辑时保留的区别 |
| --- | --- |
| 线索、用户、人头、订单、报科 | 不同计数单位不能互换；去重粒度以当前材料为准 |
| 退前、退后、留存、转化 | 保留分子分母、是否扣退、状态截点与期间口径 |
| 收款、退款、净收、收入、GMV、利润、ROI | 保留金额或效率指标各自定义，不能用近义表达替换 |
| 沟通、好友、外呼、出勤、听课 | 保留事件、阈值、课前课后或累计窗口，不能合并为泛化的参与度 |
| 顾问、班级、渠道、学生或家长 | 保留分析层级，区分付费决策者与学习者，不将组织指标归为个体效果 |
| 相关差异、因果效果、管理阈值 | 分组表现只能描述差异；不能据此声称延长沟通必然提高转化，或存在已验证的最佳时长 |

这些是表述检查项，不是 KPI 计算公式或行业基准。线上教育经营表现不能直接写成学习效果，出勤或听课时长不能直接写成掌握程度。课程到期、退款观察不完整等若影响比较，要保留在相应结论旁。

不把小样本优势外推到全部渠道，不把不同年级、产品、周期或人群构成造成的差异直接归为顾问能力。不根据两组均值推导因果、最优阈值或新增管理目标。无法证实的原因使用有明确范围的假说措辞，不能靠叠加“可能、一定程度上”掩盖信息缺失。

## 述职与工作总结保留成果归属

让读者知道解决了什么问题、本人负责什么、交付了什么，以及材料能证明哪些结果。可以解释已有工作如何支持部门目标，不能把参与写成主导、把团队结果写成个人结果、把工具能力写成已实现收益。

区分完成候选方案、完成测试、提交审批、上线、使用反馈和业务效果。任务已经有据可核时保留准确数量、日期和状态；只有计划时保持计划语气。下一步建议不冒充已承诺的个人或组织目标。

## 日报三字段格式

用户只要求按简短描述整理工作日报、未指定其他样式时，使用模板中的三个字段，各字段写一段完整自然语言，不使用多级 Markdown 标题或子清单：

```text
工作内容：完成或推进的具体事项。
完成情况：已确认的交付、进度、结果与必要阻碍。
明日工作计划：材料中已说明的下一步安排。
```

上面是结构示意，不把占位句当成最终内容。缺少明日安排时写“暂未提供”，或在允许建议的任务中明确列为建议，不替用户承诺工作。用户指定周报、其他字段或表格时遵循本次格式。

## 报告边界示例

以下均为虚构例句，只演示编辑判断。

**转化差异不证明沟通效果。** 材料：“渠道 A 中，课前沟通 10 分钟以上组转化率为 12%，其余组为 8%；未控制人群构成。”可写：“渠道 A 的课前沟通 10 分钟以上组转化率为 12%，高于其余组的 8%。两组人群构成尚未控制。”不能写“将沟通时长提高到 10 分钟可使转化率提升 50%”。

**不能把净收改成利润。** 原文：“本季度净收增长 6%，成本数据尚未齐备。”保留净收及成本缺口，不改为“盈利能力增长 6%”，也不据此生成 ROI。

**述职不升级工作状态。** 材料：“参与完成预警方案设计，试点尚未开始。”可写：“参与完成预警方案设计，形成待试点的方案。”不能写“主导预警体系落地，显著降低经营风险”。

**日报不补造上线。** 材料：“修复查询逻辑，本地校验通过，等待业务确认。”完成情况应保留“本地校验通过、待业务确认”，不能写“已上线并获业务验收”。
