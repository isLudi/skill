# 从材料生成数据与行业报告

用于根据材料生成完整报告、统计简报、运行分析、行业专题或指数解读。以清楚的研究或管理问题组织数据，交付有依据、前后连贯的成稿。

局部语言编辑见 [报告写作](report-writing.md)，篇章重排见 [结构改写](structural-rewriting.md)。

## 建立写作依据

识别读者、核心问题、期间、范围、格式与篇幅。将拟写的主张对应到当前材料的位置。

长报告可在内部为每节明确：要回答的问题、所用指标、对象与期间、单位与基准、主要判断、对应图表以及与全篇的关系。短报告据此直接组织段落。

优先用已有信息完成写作，围绕实质影响判断的缺口补齐必要背景。按材料的实际信息量选择章节和详略。

## 按用途安排结构

| 报告类型 | 信息次序 |
| --- | --- |
| 统计快报与信息直报 | 范围与主要态势，重要结构和变化，统计说明 |
| 区域与经营分析 | 总体表现，分组与对照，异常和约束，管理动作 |
| 行业与政策专题 | 明确问题，呈现表现，解释约束，提出建议 |
| 指数评价 | 评价对象与方法，结果与维度差异，讨论与建议 |
| 对外摘要与发布稿 | 发布事项与核心发现，相关证据，范围与来源 |

根据本次要求组合内容。客观监测着重发现，专题研究展开解释，决策报告突出需要回应的问题与行动。

## 将数据组织成段落

用受材料支持的判断开篇，接上直接相关的数据和比较条件，再展开解释、例外或影响。

围绕问题选择分项。规模与速度帮助判断增长表现，结构与增速帮助理解贡献，地区、品类或渠道帮助说明总体结论的适用范围。将主要反例与总体发现一起呈现。

区域分析清楚区分本地、上级整体与同级基准。不同层级的材料各自说明对应对象的表现。

对原因的叙述依照已有证据展开。将实际观察、解释假说和行动建议放在清楚的位置，让读者看见从发现到判断的联系。

## 用准确语言表达数据关系

| 数据关系 | 表达方法 |
| --- | --- |
| 累计与当期 | 写出覆盖期，将累计与单期表现分别说明 |
| 同比与环比 | 明确基期和比较频率 |
| 规模与增速 | 分别呈现规模、增速及其变化；正增长放缓时写清这两个信息 |
| 降幅与方向 | 说明变化的方向与幅度，保留原数值的符号含义 |
| 比例与百分点 | 交代分母和比较对象，采用相应单位 |
| 位次与得分 | 将位次、指数与业务表现分别表述 |
| 缺失、零值与舍入 | 沿用材料的状态标记与精度，必要时说明舍入情况 |
| 代理指标与实际效果 | 用监测、关注、招聘、订单等指标的实际含义描述发现 |

数值与单位按当前材料和交付规范呈现。需要转换或派生计算时，采用明确输入与口径，保持结果可追溯。

## 让图、表与文字各司其职

正文回答关键问题，表格保留数值细节，图形呈现趋势和差异，图注交代影响理解的条件。

将文字判断与对应证据相连，使用实际可读的数值和关系。对双栏、文本框、目录、图中标签与修订内容，先辨认版式功能，再理解正文。按交付规范安排图表、编号和注释。

## 建议回应具体发现

每项主要建议连接相应问题、行动对象、具体措施与实施条件。有材料支持时，进一步说明验证指标、资源与推进安排。

已有行动与新建议采用各自的阶段表述。研究发现提供方向，具体方案说明在什么条件下、通过什么过程落实。

## 形成完整成稿

写完正文后提炼摘要，连通标题、主要发现与建议。核对数字、统计范围、图文关系和层级指代，直接交付本次要求的完整报告。

## 新编示例

以下示例均为新编。

**增长放缓。** 本期增速仍为正且低于上期，可以写规模继续增加、增长速度放缓。

**结构变化。** 一个渠道份额降低、总市场扩大时，先说明份额与总体各自的变化，再结合该渠道金额解释其规模表现。

**监测范围。** 来自单个平台的业务数据，表述时写清平台、业务类别和观察期间。
