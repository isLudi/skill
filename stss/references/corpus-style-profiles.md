# 文体与表达选择

本地论文、批注、报告与写作规范的抽象结果。材料定位见 [本地语料来源](local-corpus-sources.md)。以当前读者、用途、作者样稿和目标规范选择适合的表达。

## 文体决定信息重心

| 文体 | 读者关心的问题 | 组织方式 |
| --- | --- | --- |
| 经济学、能源环境实证论文 | 研究什么、依据什么、发现什么 | 问题引入，文献定位，理论与证据连接，回应研究问题 |
| 问卷型管理与社科论文 | 概念如何测量、关系在何种条件下成立 | 研究情境，概念关系，样本与操作化，结果及理论讨论 |
| 理论与政策文章 | 概念如何理解、问题如何解释 | 概念辨析，解释比较，推理展开，现实条件与路径 |
| 统计监测、运行简报、信息直报 | 指定期间发生了哪些重要变化 | 范围与态势，结构对照，重要例外，统计说明 |
| 指数评价、行业专题与政策咨询 | 如何评价、差异在哪里、怎样回应 | 评价依据，关键差异，问题解释，针对性建议 |

按实际内容组合这些功能。稿件状态与正文共同帮助识别其可借鉴部分；批注用于理解具体编辑意图。

## 实证论文让问题贯穿全文

背景选择能解释问题的事实与制度条件。研究分歧引出尚待回答的关系，文献比较说明本研究的切入位置。

综述按主题、解释路线或研究设计归纳。概括已有认识，比较对象与条件，再说明本研究实际处理的部分。贡献落到具体工作与它带来的新增认识上。

理论段落交代主体、约束和行为变化，逐步连接解释变量与研究结果。不同主体或路径可以分类展开。理论假设、机制说明与后文检验使用相互对应的概念。

实证叙述先呈现主要发现，再解释比较条件、量级和证据位置。机制、异质性、调节与拓展分别回应各自的问题，形成清楚的分析层次。

## 问卷与管理研究连接概念、测量与讨论

从理论构念写到题项或代理指标、编码和观察单位。用变量的实际含义组织语言，让名称、测量与解释相互对应。

样本说明交代调查情境、接触对象、收集时点、筛选理由与分析范围。按材料具备的过程组织叙述，突出影响解释的样本特征。

调节段落说明哪种条件改变了哪一关系；中介段落解释传导路径。分组分析交代组内发现，并依据相应比较说明组间差异。

讨论回到原有理论问题，说明发现补充了什么认识，以及这种认识适用于哪些对象和条件。

## 理论与政策文章靠推理推进

界定概念及其使用范围，说明需要解释的问题，再用已有理论、制度材料或案例展开推理。

段落可分别承担定义、辨析、解释、反驳与提出条件等功能。必要对照、反例和推导关系形成文章的推进。政策路径连接现实约束、作用对象与可行行动。

## 统计与行业报告让比较关系可见

以关键判断引出数据和比较条件，区分规模、增量、增速、份额、位次与分布。

总体与分项、当地与基准、累计与当期各有层次。选择能够解释主要表现的结构差异和重要例外。简报集中呈现发现，长篇专题展开解释与建议。

分析标题可以概括受证据支持的判断，方法与范围标题则清楚命名所说明的事项。让读者通过标题理解文章如何展开。

## 按功能选择措辞

| 表达任务 | 用词依据 |
| --- | --- |
| 说明研究工作 | 考察对象、测量指标、估计关系、检验命题、解释含义 |
| 说明证据 | 分清监测、调查、估计和预测，写出材料来源 |
| 呈现变化 | 说明规模、速度、幅度或份额的具体变化 |
| 说明结构 | 交代组成、集中程度、相对位置与差异 |
| 解释过程 | 连接行为、约束、条件与相应结果 |
| 提出行动 | 明确对象、动作、依据与实施阶段 |

术语在定义与关键论证中保持稳定。通过主语、句序与信息层次变化形成自然节奏。正式表达、必要列举和准确衔接共同服务文章用途。

## 跨材料迁移写作方法

学习信息选择、推理方式、标题重心和篇章组织，用当前材料写成新的文章。具体研究与业务内容依据本次任务确定。完整报告的生成见 [报告生成](report-generation.md)，全文改写见 [结构改写](structural-rewriting.md)。
