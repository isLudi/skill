# 中文学术写作与按需翻译

用于经济学、管理学、社会科学论文、学位论文、综述、研究报告及其摘要。只处理当前请求的表达与论证呈现，不把润色扩展为重新设计研究或运行实证分析。

## 依据研究范式与章节选择检查项

从现有材料识别研究问题、对象、方法、章节作用和写作阶段。期刊、院校、导师要求和用户样稿优先；未实际查看目标规范时，不声称已符合某刊要求。

| 材料或章节 | 编辑重点 |
| --- | --- |
| 摘要 | 用研究问题、已有方法、主要发现与相称意义构成独立概括 |
| 引言 | 尽早写清研究什么、为何值得研究、做了什么和主要发现，避免宏观背景掩盖主线 |
| 文献综述 | 按问题、机制、方法或分歧组织，交代已有认识与本研究的关系，保留准确归因 |
| 数据与方法 | 保留来源、时间、观察单位、样本边界、变量定义及识别条件，消除指代与步骤歧义 |
| 实证结果 | 先呈现主要发现，再解释量级、比较对象和已有不确定性，绑定对应表图与模型 |
| 理论论证 | 保留假设、命题、适用条件与推导关系；可先解释经济或管理含义，再呈现形式表达 |
| 质性、案例、访谈或人文论证 | 以问题、材料和解释推进，保留材料语境与反例，不强加回归、实验或统计显著性模板 |
| 讨论与结论 | 区分发现、解释与启示，回应研究问题，保留外推条件，不引入此前没有的新结果 |

这是按需检查表，不要求每篇论文采用相同目录，也不要求每段填满所有项目。开题或研究计划使用拟开展、预期等准确阶段用语，不能写成已获得结论。

## 经济学、管理学与社会科学表述

写清主要发现的对象、方向、量级、单位、比较基准和适用范围，以材料具备的信息为限。保留系数、标准误、置信区间、显著性阈值、样本量和模型编号，不随手改舍入精度，不把表中其他规格当成正文主结果。

- 相关、预测、因果是不同主张。描述性分组或普通相关分析不能因句子更流畅就改成“导致”“驱动”“提升了”。
- 使用 DiD、IV、RDD 或 RCT 的名称本身不证明识别成立。沿用实际设计、假设、诊断和作者提供证据所支持的主张，不能靠方法缩写增强因果强度。
- 区分统计显著、经济量级与管理价值。“显著”不能作为“大幅”“重要”的装饰；也不能把业务上的明显变化伪装成已通过统计检验。
- 未拒绝零效应不等于证明没有效应。保留已有的估计值与精度；宽区间不能写成“证实不存在影响”。
- 区分百分比与百分点，系数与弹性，水平与对数，个体与组织，组内与总体，短期与长期。原文口径不明时标记待核对，不替作者猜。
- 机制解释、异质性结果和稳健性检验各有作用。分组差异或控制变量增加后系数稳定，不能自动写成“机制得到证实”或“排除了所有偏误”。
- 个案、便利抽样和受访者意见只支持相应对象内的叙述。不能把“部分受访者认为”改成“公众普遍证实”。

政策与管理启示须能接回已有发现，写清适用对象、条件与可能权衡。没有成本或收益证据，不补写定量收益与最优阈值。材料不足以判断机制时保留其假说性质；没有结论性证据时不替研究补造一个“明确结论”。

## 引文、术语与实质问题

保留作者、年份、文献编号、引用键、引号内容以及与其对应的命题。不把引述对象研究了某主题，改写成其证实了某结论；二手转述不能变成已阅读原始研究。

润色不默认要求重新联网核验每条引用。只报告实际核验的范围；需要新增或验证来源时，按任务权限另行检索。未核验内容标为待核验，不编作者、刊名、DOI、页码或政策出处。

“国内外鲜有研究”“首次证明”“填补空白”等贡献判断须有依据。可把已有贡献写得具体，但不能靠改写替研究增加优先权。研究事实或逻辑本身存在缺口时，用 `AUTHOR_CHECK` 分开说明；完整保留可安全润色的部分。

## 摘要写作

从正文提取摘要，不从题目猜结果。已有摘要仅需润色时保留其篇幅与必要结构；用户指定的字数、标签和院校规范优先。

完整硕士学位论文摘要且未指定其他规范时，可采用用户模板的约 1000 字方案：背景与意义约 200–300 字，问题与研究思路约 200 字，主要发现和有依据的政策启示约 300–500 字，已有创新约 100–150 字。根据正文信息与总字数调整，不机械凑齐段数或字数。

期刊摘要、会议摘要和短摘要按本次要求组织，不套用硕士篇幅。优先让读者明白研究问题、如何研究、发现什么、可以说明什么。研究尚未完成或材料缺少结果时，不能虚构发现、创新或启示；若这使所要求的完整摘要无法成立，简要指出缺少的关键材料。

输出 `<摘要>`、`<修改后内容>` 等仅限用户要求时使用。单纯润色不附审校过程；需要作者确认的实质缺口另行简短说明。

## 中英学术翻译仅在明确要求时进行

指定英文、英译中或双语时再翻译，不能把中文润色自动变成英译。建立一致的术语对应，保留变量、数字、引用和证据强度。

可以按目标语言重组语序、主动或被动结构与修饰关系，以自然、准确为准；不强迫全部被动、倒装或强调句。经济学英文宜尽早呈现问题与发现，不能把这种倾向变成所有中文文体的固定段落配方。

## 学术边界示例

以下均为虚构例句，只演示编辑判断。

**相关不能变成因果。** 材料：“横截面调查发现，培训参与度较高的员工满意度也较高。”可改：“横截面调查显示，培训参与度与员工满意度正相关。”不能写“培训提高了员工满意度”。

**保留未显著结果。** 材料：“估计系数为 0.03，p = 0.12，未达到 5% 显著性水平。”可改：“估计系数为 0.03，在 5% 水平上不显著（p = 0.12）。”不能写“研究证明该变量没有影响”。

**不靠同义替换改变命题。** 材料：“本研究考察绩效考核与组织学习的关系，尚未检验中介机制。”保留“考察”与“尚未检验”，不能改成“揭示绩效考核通过组织学习提升企业绩效”。

**不填造摘要。** 只提供研究计划和方法，没有发现与创新材料时，可以润色已有计划或起草研究计划摘要，不能冒充已完成论文的结果摘要。
