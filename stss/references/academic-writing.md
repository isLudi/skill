# 学术写作与按需翻译

用于经济学、管理学、社会科学论文、学位论文、综述、研究报告及摘要。依据研究范式、章节作用、写作阶段与目标规范选择表达。语体选择见 [文体与表达选择](corpus-style-profiles.md)，全文重写见 [结构改写](structural-rewriting.md)。

## 按章节任务组织语言

| 材料或章节 | 写作任务 |
| --- | --- |
| 摘要 | 独立交代研究问题、已有方法、主要发现与研究意义 |
| 引言 | 尽早明确问题、研究位置、所做工作与主要发现 |
| 文献综述 | 按主题、机制、方法或分歧组织已有认识，并定位本研究 |
| 数据与方法 | 说明数据、观察单位、样本形成、变量含义与识别依据 |
| 实证结果 | 呈现主要发现、量级、比较条件及对应证据 |
| 理论论证 | 界定假设与概念，解释推导关系及命题的适用条件 |
| 质性、案例与访谈研究 | 连接研究问题、材料语境和解释，说明案例所支持的认识 |
| 讨论与结论 | 回应研究问题，阐明发现的含义、贡献与适用范围 |

以章节实际承担的任务安排篇幅和顺序。研究计划使用与其阶段相符的预期和拟开展表述；完成稿使用已经获得的材料与发现。

## 实证语言写清关系与量级

让对象、方向、量级、单位、比较基准和适用范围相互对应。正文采用与主结果一致的模型、规格和表图。数值精度与统计符号按本次规范统一。

相关关系用关联或相应变化表述，预测关系说明预测对象和时序，因果判断依照实际识别依据表述。方法名称用于交代研究设计，假设与诊断用于解释其识别范围。

统计显著性说明估计的统计证据，经济量级说明实际幅度，管理价值联系问题与行动。未达到显著性水平的结果，用估计值与精度说明其含义。

将百分比与百分点、系数与弹性、水平与对数、组内与总体、短期与长期分别写清。机制、异质性、调节和稳健性各自回答对应问题。

## 问卷研究连接构念与测量

依次说明理论概念、实际题项或代理指标、编码与观察层级。调查情境、样本接触、收集时间、筛选与最终分析范围分开交代。

调节关系写清什么条件改变了哪一变量关系；中介关系写清所讨论的传导路径。分组结果先呈现各组发现，组间结论采用对应的比较证据。量表与多层设计按实际研究说明。

## 讨论让发现进入学术对话

说明发现与前文理论、相关研究之间的联系：支持了哪种认识，解释了什么分歧，补充了哪些对象或条件。贡献落到实际完成的工作上。

政策与管理启示由发现引出，说明行动对象、适用条件与可能权衡。限制放在影响解读的位置，未来研究围绕尚待回答的具体问题展开。

引文与主张保持准确绑定，统一作者、年份、编号、引用键和术语。需要核实的实质问题在审阅中定位；普通语言润色聚焦表达本身。

## 摘要根据正文形成

以正文的研究问题、方法和结果为依据提炼摘要。已有摘要的局部润色沿用其篇幅；完整摘要按指定院校、期刊或会议规范组织。

用户采用硕士摘要模板且未另给规范时，可按约 1000 字安排背景与意义、问题与研究思路、发现与启示、已有创新。按信息量分配篇幅，让发现占据应有位置。其他摘要依据本次篇幅选择重点。

按要求使用 `<摘要>`、`<修改后内容>` 等标签，直接交付所需文本。

## 按目标语言重组学术表达

明确要求英文、英译中或双语时，建立术语对应，并按目标语言调整语序、主被动结构与修饰关系。让问题和发现容易识别，保持原有概念与论证关系。

## 新编示例

以下示例均为新编。

**相关表述。** 横截面调查观察到培训参与度与满意度同向变化，可以写“调查显示，培训参与度与员工满意度正相关”。

**统计表述。** 某估计未达到预设显著性水平时，报告估计值与相应精度，说明当前证据所支持的判断。

**贡献表述。** 研究扩大了观察层级并补充新的分析条件时，直接交代扩展在哪里，以及它帮助回答了什么问题。
