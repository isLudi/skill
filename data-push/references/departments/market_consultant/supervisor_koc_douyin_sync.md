聚合公式：

- 线索留存率 = `Σ退后线索 / Σ退前线索`；各过程率 = 对应标记合计 / `Σ退后线索`。
- 总通时 = `Σ总通时秒`；外呼频次 = `Σ外呼次数 / Σ退后线索`。
- 单效（当期）= `Σ当期净收款 / Σ退后线索`；人均报科 = `Σ报科数 / Σ成交人头`。
- 人头转化 = `Σ成交人头 / Σ退后线索`；订单转化 = `Σ报科数 / Σ退后线索`。
- 退费率 = `Σ退费 / Σ收款`；单效 = `Σ净收款 / Σ退后线索`。
