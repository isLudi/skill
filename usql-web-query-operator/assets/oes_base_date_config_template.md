# OES 导出配置表模板

`base-setup` 创建“导出配置”数据表。`sync-base` 每次从选定的启用记录读取开始时间，截止本次运行时刻，查询完整区间并全量覆盖目标明细表。开始时间不会推进；无需维护结束日期，也不是增量游标。

| Base 字段 | 类型 | 示例 | 用途 |
|---|---|---|---|
| 配置名称 | 文本，主字段 | OES订单全量同步 | 配置说明 |
| 开始时间 | 日期时间 | 2026-06-19 00:00 | OES 查询起点，上海时区 |
| 启用 | 复选框 | 已选 | 允许手工/计划任务执行，不自行启动调度 |
| 数据表ID | 文本 | tbldVzfsawwH5a1A | 唯一绑定待覆盖的明细表 |
| 最近运行标识 | 文本 | 配置ID_20261004_1630 | 完成后自动回写，同次重试保持标识 |
| 最近运行状态 | 文本 | completed | 完整数据核验成功后回写 |
| 最近截止时间 | 日期时间 | 本次固定截止时刻 | 自动回写，不用手动填 |
| 最近完成时间 | 日期时间 | 实际完成时刻 | 自动回写 |
| 最近明细行数 | 数值，整数 | 11013 | Excel / Base 完整核验行数 |

初始开始时间采用用户指定的 **2026-06-19 00:00 Asia/Shanghai**。同一目标表必须只有一条被选中的启用配置；初始化重跑不会重置维护的起点。

无需手工限制为 30 或 60 天。脚本根据完整查询自动切分超过 1 万条的区间，单日超量时继续按毫秒切分。上一段结束后 1 毫秒即下一段开始；查询、各附件及合并文件核验通过才继续写 Base。

数据表写入全部 13 个 Excel 字段：时间、订单号、班级bizNumber、班级名称、业绩归属类型、用户姓名、手机号、userId、业绩金额、业绩归属人、转介绍归属类型、状态、是否扣绩效。全量备份/删除与 OES/邮件并行，写入和删除每批 500 条，读取每页 2000 条，直到 `has_more=false`。重复订单流水保留。

运行电脑的路径、邮件等待和扫描参数使用 [oes_base_job.example.json](oes_base_job.example.json)。邮件独立的绝对/滚动日期任务仍可用 [oes_mail_job.example.json](oes_mail_job.example.json)，它不控制 Base 全量同步的起点。

密码、Cookie 和登录态不放入 Base 或 settings.json。两站均从 `usql_api.env` 的精确 OES 凭据区段读取账号密码；每台电脑自行授权并保存状态。
